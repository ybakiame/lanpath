# 订阅切换与运行缓存验证（2026-10-14）

## 根因与修复

代理节点共享 PROXIES_KEY，默认缓存 30 秒仍视为新鲜；启停仅回写状态，不清除旧运行数据。新核心启动后首页/代理页面可能先复用上一份节点结果，旧轮询晚返回也可能覆盖新状态。桌面订阅选择又未阻止保存过程中启动。
共用 writeRuntimeStatus 用于双端首页启停与重启提示：先取消状态轮询和策略/活动连接请求，再回写状态、重置运行查询。仅启动成功后刷新已挂载查询；停止时不向核心重拉。桌面订阅/核心切换完成并重读配置前，禁用重复选择与启动。
代理页按运行状态启用查询；运行中读取失败展示 API 错误和重新读取操作，不误报核心未运行。
