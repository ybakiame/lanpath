# ADR-0006：订阅原文与仪表盘覆写配置

- 状态：Accepted
- 日期：2026-10-15

## 决策

订阅拉取器在格式识别与转换前保留 UTF-8 响应文本，单独写入
`subscription_cache/<id>.source.json`（内容与识别格式）。现有 `<id>.json` 的
sing-box 节点缓存和运行配置合成方式保持不变。此缓存仅包含成功解析的响应，
保留注释、BOM、空白、CRLF 和 base64 原始表示，不从转换结果重建订阅。
非 UTF-8 响应明确报错，避免静默替换字符后声称是原文。

原文读取与导出不发网络请求。历史订阅没有原文时提示刷新；刷新失败保留上次成功原文，
更改 URL 和删除订阅时与节点缓存一起清理。不会批量迁移或重拉已有订阅。

新增共享命令 `subscription_source(id)` 返回 content/extension；
`export_subscription_source(id)` 读取后端缓存并导出，返回展示路径。
YAML、sing-box JSON 和分享链接分别使用 `.yaml`、`.json`、`.txt`。
桌面导出至系统下载目录下的 Lanpath 文件夹，Android 复用 MediaStore Downloads
适配方式写入 Download/Lanpath，无额外存储权限。文件名由 UUID 生成，避免覆盖。

订阅页统一为双端自适应卡片，不再放覆写关联控件或合成配置预览；合成预览保留于桌面仪表盘。
仪表盘新增当前订阅覆写选择与模板管理链接，模板页成为共享路由。
仍按订阅保存 profile_id，不增加全局模板字段、不改变已有绑定。
新增 `set_subscription_profile(id, profileId)` 仅修改关联并校验模板存在；
保存期间禁止启动和切换生效订阅，运行中保存提示重启。
订阅拉取完成只合并抓取元数据，避免覆盖期间修改的模板、名称与启用状态。

## 边界

原文含订阅本身的完整内容，导出是用户主动操作；普通列表仅展示订阅域名，
原文弹层关闭后立即回收查询缓存。未将私有订阅响应放入日志或仓库。
浏览器 mock 只验证界面和命令契约；Windows/Android 文件落盘和安装升级须由真实设备验收。
