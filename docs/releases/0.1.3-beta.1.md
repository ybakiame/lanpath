# 岚径 Lanpath 0.1.3-beta.1

本次测试版新增加密备份迁移和独立请求代理设置，修复 Android 恢复耗时、首次 VPN 授权等待及重复弹窗。

## 更新内容

- 备份与恢复：密码加密 .zip.age 文件，可生成并复制随机密码；导入先查看摘要，再确认完整替换，自动保留加密恢复前副本。
- 保持加密强度，优化 Android 密码计算；复用一次性预览结果，确认恢复时不再重复解密。
- Android 首次点击启动先请求 VPN 授权；切页再回来仍显示进行中，重复点击不会排队产生多个授权弹窗，取消后可手动重试。
- 网络请求设置独立于 GitHub 镜像，支持不使用、系统、核心、自定义 HTTP(S)/SOCKS5 代理。
- 修复订阅压缩响应与需连续请求的 cookie 会话兼容，订阅原文仍保留。
- 修复 Windows TUN 管理员权限识别，提权后退出旧实例。

## 下载与升级

Windows x64/arm64：安装版选 -setup.exe，便携版选 -portable.zip；Android arm64：选 _android_arm64.apk。
Android 最低版本仍为 13，沿用现有发布签名，可覆盖安装。Windows 安装版仍使用 ~/.lanpath，
便携版保留程序旁 data 目录。无需卸载旧版，不删除个人数据。

测试版继续通过「检查更新」进入发布页手动更新，不进入稳定自动更新通道。

## 备份与代理说明

此前测试构建导出的备份格式继续兼容。恢复替换配置并停止代理，重启后生效；Android 点击关闭应用按钮，再从桌面打开。
核心、证书私钥、日志、流量历史和系统授权不迁移，系统代理/TUN/MITM 需重新开启；密码遗失无法恢复。
旧请求代理开关保留原选择，新用户默认系统代理。直连无法下载订阅时，可选择系统代理或运行中的核心代理。

## 验证边界

本地验证与 CI 覆盖双端前端、Rust、启动状态缓存、备份加密与凭证回归、Android Kotlin/资源及构建。
主机备份测试耗时显著改善，Android 真实速度仍取决于设备。用户已确认此前 Windows 导出→Android 导入可以工作；
本版优化后的设备耗时、首次授权与重复点击路径仍需真机验收。
Windows 无 Authenticode 代码签名证书；updater 签名与 Android 发布签名沿用现有身份。
