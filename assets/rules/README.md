# Rule catalog

Static rule names from the `sing` branch of [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat), under `geo/geoip/*.srs` and `geo/geosite/*.srs`.

One rule name per line. This is the existing catalog extracted without changing its entries. Consumers construct the upstream download URL and search locally; no GitHub API call is required at runtime.
