# ADR-0008：加密备份与启动时恢复

- 状态：Accepted
- 日期：2026-10-17
- 决策来源：用户要求密码加密压缩包、跨客户端恢复，并明确同意完整替换、恢复前保留副本。

## 格式与性能

备份为 `.zip.age`：ZIP Deflate level 3 压缩后，通过 age v1 scrypt 密码接收方整体加密。
不使用传统 ZipCrypto，不自定义加密算法，文件清单、订阅凭据和正文均在认证加密内。
使用 age 0.12.1（关闭默认特性）；v1 统一 scrypt log N=17（约 128 MiB 内存），
解密限制最高 17，避免恶意备份要求无限内存。阻塞任务承担压缩/KDF，进程内串行加解密，
不在 WebView 主线程执行。密码至少 12 字符、最多 1024 UTF-8 字节；可生成 24 位随机字母数字密码。
密码不持久化、不记录日志、不随文件导出；复制由用户触发，遗失无法找回。

首期压缩包上限 16 MiB、解压上限 64 MiB、最多 1024 个业务文件。解压检查实际读取长度，
拒绝绝对路径、穿越、符号链接、重复/大小写重名、Windows 保留文件名及白名单外文件。
仅接受格式版本 1，压缩包包含加密 manifest（版本、时间、平台、计数、外观）。

## 范围与适配

包含 client.json、subscriptions.json、profiles.json、local_override.json、config_slices.json、
remotes.json，以及 subscription_cache、profile_cache、scripts、remote_cache、script_store。
不备份核心、CA/私钥、日志、流量库、WebView 数据、运行缓存、已下载规则集和图标。
外观仅备份主题/强调色/纯黑偏好，不复制浏览器存储或会话。

源数据目录下的 JSON 路径转为逻辑占位符，导入后重定位；外部文件引用由用户检查。
导入保留目标设备的核心路径和 CA 目录，不复制系统授权；系统代理、TUN、MITM 关闭，
跨平台时采用目标 TUN 栈默认值。已有证书仍留在目标设备，首次使用 MITM 按本机流程授权。

## 恢复事务

导入先完整解密、校验结构及订阅/模板关联，仅返回摘要。确认后再次校验文件，停止核心，
以同一密码导出当前状态到私有数据目录 backup-history，供「使用恢复前备份」再次导入。
不合并订阅，不自动启动代理。受支持根目录完整替换，备份中缺失的条目在目标中移除。

恢复准备存于私有临时目录，完整写入后原子发布为 `.backup-pending`；此后 UI 阻止继续操作。
桌面通过 Tauri request_restart，Android 通过用户按钮关闭应用进程，再手动重开。启动在日志/状态机/核心
初始化前应用恢复，避免后台刷新和脚本写入并发。每个根目录先移动到事务原件目录，再替换；
持久化 journal 标记提交。中断时回滚已移动条目再重试；提交后仅清理事务，不回滚已完成配置。
待恢复校验失败且原配置完整时隔离待恢复目录，继续启动旧配置并提示重试；无法回滚的 journal 错误则停止启动。
原件在事务完成后清理，用户可恢复的加密副本持续保留，不自动删除历史备份。

外观恢复结果在磁盘保留至前端应用偏好后确认；配置恢复失败不提前改变 UI 偏好。
错误密码、篡改、不支持版本等在准备阶段拒绝，不改写现有配置。

## 边界

首期不提供合并、云备份、自动定时备份，不跨应用导入其他产品格式。
备份可包含会执行的脚本，导入确认页明确要求可信来源；加密不是代码来源认证。
恢复前副本要求当前配置可读取并通过校验；损坏配置不被静默忽略。
Android MediaStore、原生文件选择、Windows 实际重启以及跨设备运行需真机验收。
