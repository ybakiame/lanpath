# 移动端外观验证（2026-10-11）

## 范围

移动首页、配置入口、设置外观、共享移动卡片与安全区间距。
启停按钮从悬浮操作改为连接卡内操作，原有 Dashboard mutation 与 VPN 授权重试链路继续复用。
外观新增四种强调色，保留浅深/系统及 iOS/Material 偏好；没有配置迁移、后端或依赖变更。

## 检查

- 项目 Nix 环境：`lanpath-app verify`（桌面及 Android 前端 build、lint、format）、
  `@lanpath/ui verify` 与 `@lanpath/client-core verify` 通过。
- 构建保留既有 React Compiler finally 优化跳过提示和大 chunk 提示，不影响构建通过。
- 浏览器使用 Android mode 与 `browser-debug=1` mock IPC，检查首页空态、配置入口与设置页面。
- 390×844、375×812 和 812×375 检查无横向溢出；375px 首页主要按钮高度不少于 44px。
- 深色湖水青选择后刷新恢复正确；检查 `--primary` 与 `--accent` 一致，修正旧移动蓝色令牌的覆盖。
- 会话内注入演示订阅及今日流量后，点击启动确认状态变为已连接、按钮变为停止代理，
  点击停止后恢复准备连接状态，今日指标正确呈现；演示数据没有写入产品源码。
- 四种强调色 × 浅深主题共八种组合，运行时 primary 与 accent 一致，页面没有横向溢出。
  使用 WCAG 相对亮度公式核对实心按钮文字对比度：浅色 4.88–5.93:1，深色 8.14–10.59:1。
  次级正文令牌在对应基础背景上为 5.24:1（浅色）、6.70:1（深色）。
- 浅色首页、深色设置及深色 Material 配置页的 axe WCAG A/AA 检查未发现自动化违规。
  页面渐变背景及装饰选中符号的对比度为自动化 incomplete，不等同于全面 WCAG 认证。

## 设备边界

本轮为前端与浏览器 mock 验证，没有安装 APK 或测试真实 Android VPN 授权、系统栏、
软键盘、系统字体缩放与设备性能。Android 前端构建通过不代表设备验证完成。
