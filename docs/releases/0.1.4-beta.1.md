# 岚径 Lanpath 0.1.4-beta.1

本次测试版带来移动端水波连接卡片、规则集分类与检索，并改善跨设备恢复后的首次启动体验。

## 更新内容

- 移动端连接卡片使用随连接状态变化的三层水面，触摸产生柔和扩散的涟漪；文字与按钮保持稳定，沿用主题强调色。
- 支持系统减少动态效果，离屏或后台暂停持续动画，纯黑模式降低装饰亮度。本版先验证视觉与触摸反馈，尚未接入陀螺仪。
- 规则集支持自定义单分类、市场添加时分类、列表检索筛选及批量整理；路由与 DNS 的规则集选择支持名称/tag 检索和分类筛选。
- 市场新增条目可选 GitHub Raw/jsDelivr；更新使用条件请求及内容比较，不再依赖不可靠的上游时间戳，显示最近检查时间。
- 加密备份 v2 包含规则集本地文件，减少跨设备恢复后重复下载；旧 v1 备份仍可导入。
- 启动只补下载实际启用规则引用的缺失文件，双端展示授权、配置合成、规则集准备及核心启动阶段。

## 下载与升级

Windows x64/arm64：安装版选择 `-setup.exe`，便携版选择 `-portable.zip`；Android arm64 选择 `_android_arm64.apk`。
沿用既有发布签名与数据目录，可覆盖安装；Portable 保留程序旁 `data`。测试版从发布页手动更新，不推进稳定更新通道。

规则集旧配置升级前保留原始副本；已有 tag、引用和下载地址保持原语义。新备份仍使用密码加密，恢复前查看摘要并确认完整替换，保留加密回滚副本。

## 验证边界

前端与原生构建、签名验证由项目检查及同提交 CI/Release 流程执行。浏览器 mock 仅验证水面状态、触摸反馈、减少动态效果和暂停行为；不能代替真机 VPN、恢复速度、耗电、帧率及安装升级验收。
未连接设备的检查不记作真机通过。Windows 尚无 Authenticode 代码签名，updater 与 Android 发布签名沿用已有身份。
