## 压缩取舍

使用 Nix 环境 Python zlib，对 5000 条完全虚构节点组成的 1,066,683 字节 JSON 做单次比较：

| 级别 | 压缩字节 | 原大小比例 | 耗时 ms |
| --- | ---: | ---: | ---: |
| 1 | 179447 | 16.8% | 4.53 |
| 3 | 172438 | 16.2% | 4.37 |
| 6 | 155174 | 14.5% | 7.85 |
| 9 | 152690 | 14.3% | 19.78 |

这是压缩级别方向性比较，不是 Rust miniz、手机或 Windows 的性能承诺；不含密码 KDF 时间。
首期采用 3，在配置数据体积与速度间取舍；大文件/数量限制另行生效。
