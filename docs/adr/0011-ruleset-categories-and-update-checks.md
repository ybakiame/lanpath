# ADR-0011：规则集分类、检索与条件更新

- 状态：Accepted
- 日期：2026-10-18
- 决策来源：用户要求规则集分类、市场选择及各选择器检索；确认单分类、旧条目未分类并保留升级副本；确认 GitHub/CDN 可选与 ETag 更新方案。

## 分类

CustomRuleSet 增加 category 字符串，空值表示“未分类”；每个条目仅属一个用户自定义分类。
分类名称去首尾空白，最多 64 字符，不允许控制字符；不改变 id、tag、规则引用、来源或缓存文件。
可选分类从现有条目派生，不维护独立空分类表；批量改名/移入未分类后，不再被使用的分类自动不出现在候选中。
市场的 GeoIP/GeoSite 是内容类型，独立于用户分类。

市场添加、单项编辑可选择已有或新建分类；管理列表按名称/tag 与分类组合筛选，可多选并批量归类。
分类批量命令只修改指定条目，返回完整视图写回 Query，不运行缓存清理或核心重启。
共享 RuleSetPicker 供路由与 DNS 使用，筛选不改变已选集合，显示已选项并保留失效引用。

## 一次性数据升级

local_override.json 的 ruleset_metadata_version=1 标记分类及更新元数据版本。
旧文件验证可读后，先原子且不覆盖地保存 local_override.ruleset-metadata-v1.backup.json 原始字节，
再原子写入版本及未分类字段；备份或写入失败返回错误，不以新配置覆盖原件。
新配置只读新形态，旧格式从导入后首次读取执行同一升级。恢复时先关闭客户端，以副本替换原文件；
若恢复了不同的旧快照，额外副本以内容散列区分；重试复用相同原件，不覆盖或删除旧副本，不引入长期双写。普通运行文件、规则集及下载地址不在迁移时变更。
新备份已包含 local_override.json，因此分类及更新校验元数据随加密备份迁移。

## 更新状态

新增 backend-owned remote_state：成功检查时间、有效请求地址、ETag、Last-Modified 及本地 SHA-256。
保存同一资源时保留磁盘元数据和远程缓存写入时间；用户传入的校验器不生效；来源改变时清空校验元数据。
HTTP 条件 GET 优先 ETag，退而使用 Last-Modified；缺文件/指纹变化/有效地址变化时完整请求。
304 保留本地写入时间；200 比较内容，变化才原子替换并更新写入时间。成功才记录检查时间，错误及空内容保持旧缓存。
更新检查串行化而不占分类写锁，不使用设备时间比较决定结果新旧；跨设备时钟差异不阻止新检查。
更新结果回写时在短写锁中读取最新规则配置，只合并相同 id/source 的检查结果，避免慢更新覆盖期间的分类/规则编辑。

上游时间仅展示，不再比较上游时间和本地时钟判断内容版本。页面把未提供修改时间与未检查、未缓存分开。
保持请求超时、网络代理设置和 GitHub 镜像规则；市场默认 Raw，新条目可选 CDN，旧地址不自动改写。
不引入 GitHub token、后台逐文件 API 查询或自建托管服务。
