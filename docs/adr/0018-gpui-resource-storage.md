# ADR-0018：GPUI 资源清单与缓存布局

- 状态：Accepted（仅 GPUI 实验目标）
- 日期：2026-11-08
- 决策来源：用户明确选择仅 GPUI 整理资源/订阅与缓存，并进一步指定订阅独立保存为 TOML，Tauri/Android 保持原状。
- 承接：[ADR-0016](0016-gpui-unified-app-settings.md)；替代其中远程资源、订阅清单与缓存继续分散存储的部分决定。
- 同轮补充决策：用户选择补齐本地资源管理，并将配套图标纳入同一资源。

## 决定

GPUI 仍以独立数据根中的 `app.toml` 作为格式选择信号；只有 GPUI 主动创建此文件。
共享存储实现按此信号分派，Tauri/Android 没有此文件时仍使用既有 JSON 与目录，不自动转换生产数据。

| 内容 | GPUI 路径 | 属性 |
| --- | --- | --- |
| 远程资源清单 | `app.toml` 的 `[resources].remotes` | 持久配置 |
| 订阅清单与订阅元信息 | `subscriptions.toml` 的 `subscriptions` 数组 | 持久配置 |
| 远程片段及已获取 hook/task 内容 | `cache/remotes/` | 可重建 |
| 自动刷新完成尝试时间 | `cache/remotes/refresh.json` | 运行进度，不写入配置 |
| 远程纯 JS | `cache/scripts/` | 可重建，不自动绑定 hook |
| 远程图标 | `cache/icons/` | 可重建 |
| 订阅节点及原始响应 | `cache/subscriptions/` | 可重建 |
| 远程覆盖模板 | `cache/profiles/` | 可重建 |
| 本地导入注册表与独立内容 | `resources/imports/` | 持久资源，不能随缓存清理 |

使用 `cache/`，避免 Windows 上点目录不具备统一隐藏语义所带来的含义差异。
`profiles.json`、结构化配置、规则与脚本持久键值等其他领域文件保留既有格式，本次不扩展为全数据 TOML 化。
旧 `scripts/` 可能混有用户手写文件与显式路径引用，因此保留原目录；仅复制已知远程资源对应的下载到新缓存。
不自动改写任意用户脚本路径，不增加自动清理或清缓存按钮。

## 本地资源包

沿用 `resources/imports/local_imports.json` 的 UUID 注册表与 `local/<UUID>.json` 内容文件，不另增本地清单或分散的 JS/图标配置。每个内容文件扩展可选 `local` 源信息，保存资源名称、启停、方言、原始片段及内嵌图标；关联 JS 仍按 source identity 保存在同一文件的 hook/task 中。更新按同一 UUID 原子替换，停用后整个资源的规则、脚本、任务和主机名均不激活，删除先移除注册权限再删除内容。

管理入口仅在 GPUI 开放。本地解析显式支持 Surge / QX 中的文件名与 URL 作为 JS 引用，由用户粘贴或读取 JS 文件绑定；引用不授权读取路径、联网下载或执行任意宿主文件。远程与旧壳的常规导入解析仍拒绝本地路径。缺失、重复或未引用的 JS，以及未支持的片段指令阻止保存；已支持声明的运行范围提示（如 Surge 响应 `max-size=-1` 的 32 MiB 检查上限）保留显示并允许保存，保留上次成功资源；识别后移除不再引用的 JS 需要确认。PNG/JPEG/WebP 图标复制内容入资源，最大 512 KiB，不持久化宿主路径。

历史导入没有原始片段时不伪造原文，保留已有解析规则，并允许编辑已绑定 JS、名称、图标和启停；用户提供原始片段后才重新解析。旧内容在第一次实际编辑/启停时原子扩展，不增加启动迁移或迁移表单。没有新元数据的 Tauri/Android 数据保持原行为；显式恢复的新资源仍尊重其启停状态。

## 迁移与一致性

通过既有开屏迁移会话注册 `resource-layout-v1`。业务页面和后台刷新尚未创建时，依次备份旧清单、缓存、图标与脚本，解析清单并检查重复标识，复制新目录，逐文件比较字节，最后写入 `subscriptions.toml` 和 `[resources]`。迁移复用自动开屏流程，不新增输入表单或用户确认步骤。
迁移备份位于 `backup/migrations/<ID-UUID>/`，包含原件、转换结果与清单。
仅当备份、转换、校验和产物记录全部成功后，才移除旧清单与已搬迁目录；未知文件随所属旧目录保留到新目录和备份。
已存在的对应 TOML 清单为权威；遗留 JSON 不覆盖它。若试验数据中曾存在 `[resources].subscriptions`，也会自动转存到独立订阅文件并移除原字段。目标不同内容或损坏清单导致迁移失败，原件保留；相同内容允许安全重试。
不在业务运行期间执行迁移，不自动读取其他应用的数据根。

资源、订阅、应用设置与外观写入共用进程内锁，并在锁内重读、合并和原子替换各自文档，避免后台刷新与其他分区保存互相覆盖。
自动刷新仍在发布前检查存活租约及实际目标文件，不能绕过活跃核心输入保护。

## 备份与恢复

GPUI 导出 v3：携带逻辑资源/订阅清单及分类资源文件，继续加密；刷新进度、远程图标缓存、核心、证书、日志与本机外观不进入内容快照。
本地图标与片段/JS 同在持久资源中，随 v3 快照加密往返，不受缓存清理影响。
读取仍兼容 v1/v2；恢复时按目标布局映射路径，将资源清单合入目标 `app.toml`，订阅清单写入独立 `subscriptions.toml`，保留本机外观和核心选择。
旧暂存恢复完成后再次运行同一迁移会话，使离线缓存当次启动即可使用。
新旧路径同时出现且字节不同时拒绝恢复，不静默挑选或丢弃一份。
Tauri/Android 继续导出 v2，并使用既有存储根；读取器支持 v3 的显式备份导入，不触发生产目录自动迁移。
旧版程序不能读取 v3，需要使用新版读取器；仍可导入旧备份。

## 验收边界

覆盖 JSON 到 TOML、缓存/本地导入分离、冲突失败与重试、并发分区写入、旧备份映射和 v3 加密往返；Windows 使用独立测试数据根验证开屏迁移、资源 modal 与重开持久性。
本决策不授权安装或升级工具链、发布、迁移真实生产数据或扩大系统网络接管范围。
