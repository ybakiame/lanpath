# 岚径 Lanpath 0.1.2-beta.1

本次测试版新增订阅原文导出，改善订阅与覆写操作，并切换至稳定 Nixpkgs/devenv 开发环境。

## 更新内容

- 订阅原文查看与导出：YAML 保留注释与换行，JSON 保留原始排版，分享链接保留原始文本/base64；内部 sing-box JSON 转换不变。
- 下载文件按实际格式使用 `.yaml`、`.json` 或 `.txt`，位于系统下载目录的 Lanpath 文件夹。
- 双端订阅列表改为自适应卡片，列表仅展示来源域名；覆写关联从订阅表单移至首页仪表盘。
- 首页可为当前订阅选择模板或取消覆写，并进入模板管理；已有绑定保留，运行中修改需重启。
- 桌面窗口默认居中、合理最小宽高；窄窗口提供展开导航，非侧栏直达子页面提供返回入口。
- 修复切换订阅后启动仍显示旧代理策略/节点的缓存问题，以及刷新覆盖同期覆写设置的问题。
- 开发与 Linux/Android CI 使用 nixos-26.05 和固定 devenv Flake 模块，复用本地验证命令；Windows 保持锁定的原生工具链。

## 下载与升级

Windows x64/arm64：安装版选择 `-setup.exe`，便携版选择 `-portable.zip`。
Android arm64：选择 `_android_arm64.apk`，最低 Android 13，沿用 beta.1 的 Lanpath release 签名身份。
安装版数据目录仍为 `~/.lanpath`，Portable 仍在程序旁 `data/`。不自动迁移或删除用户数据。

从 `0.1.1-beta.1` 升级：使用「检查更新」打开发布页，下载相同架构和分发类型的新包。
Windows 安装版运行安装器，Android 使用同签名 release APK 覆盖安装；Portable 退出应用后替换程序并保留 `data/`。
补丁号递增，以便安装器和 Android 版本编号明确高于上一 beta。测试版仍不进入稳定自动更新通道。

旧订阅首次查看原文前需手动刷新；刷新失败保留上次成功内容。原文导出包含订阅提供的完整配置。
`.nsis.zip` / `.sig` / `prerelease.json` 用于安装版签名与更新元数据验证，`SHA256SUMS` 提供下载校验。

## 验证边界

本地已执行双端前端验证、Rust 全门禁、原文保真与缓存回归、发布工具测试及 Android 调试构建。
浏览器 mock 验证了卡片、原文/导出、缺失提示、仪表盘覆写与保存门禁。
真机文件落盘、覆盖安装、VPN/TUN、系统代理与真实升级体验仍需目标设备验收。
未提供 Linux/macOS 分发包，Windows 安装器未配置 Authenticode 代码签名证书。
