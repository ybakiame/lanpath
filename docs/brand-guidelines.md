# 岚径 · Lanpath 品牌

中文岚径，英文 Lanpath；双端展示岚径 · Lanpath，Android 启动器短名岚径。
正式产品名 Lanpath，应用标识 com.ybakiame.lanpath；域名与应用商店名称可用性未完成核验。
图标为深靛蓝 #292D63 底、白色抽象路径 L。源在 apps/client/public/brand。
在 Nix 中进入 apps/client 后运行 bun run tauri icon public/brand/icons.json 可生成各平台图标。
单色 Android 通知矢量与前景保持同形；自适应图标有独立前景、背景和 monochrome 图层。

## 客户端外观

移动端以淡雾底色、大圆角表面和深色连接主视觉组织层级；深色主题默认使用炭灰背景，可通过深色外观选项启用纯黑背景。
首页启停操作位于连接状态卡内，底部胶囊导航保留首页、配置、设置三个入口。
配置主页在 380px 及以上使用双列入口卡片，小屏回落单列；正文宽度限制为 42rem。
参考图中的图表、头像与照片不用于代理状态，指标仍来自真实核心与本地统计。

主题设置位于 `/settings/theme` 二级页，设置主页仅显示当前主题与强调色摘要。
移动端统一采用 Lanpath 外观，不提供 iOS/Material 形态切换；平台呈现通过编译期事实投影到 `data-platform`。
主题模式只有浅色、深色、跟随系统三种，强调色独立选择。
纯黑背景是深色外观下的开关：仅在实际主题为深色时生效，切换浅色后仍保留偏好；
跟随系统进入深色时应用。启用后页面、卡片、弹层及导航使用黑色底色，卡片靠细边界分层。
强调色提供鸢尾紫（移动默认）、湖水青、玫瑰粉、品牌蓝（桌面默认），图标品牌保持原色。
浅色使用深强调色与白字，深色使用浅强调色与深字；按钮、选中态及焦点复用同一语义令牌。
成功、警告与错误保留独立状态色，选择强调色不改变其语义。

主题继续使用现有 `pp-ui-theme` 存储键；强调色保存为 `lanpath-ui-accent`，
深色纯黑背景偏好保存为 `lanpath-ui-oled-black`。旧风格键停止读取，不改写或删除已有用户数据。
首帧脚本与 React Provider 使用相同值域及平台默认值，非法值回落默认；存储不可用时支持会话内切换。
颜色在 `packages/ui/src/appearance.css` 中集中定义，组件使用语义令牌，外观偏好不写入核心配置。

## 图标

界面图标统一使用 `lucide-react` 具名导入，保留默认线性描边和语义尺寸。
共享 UI 控件也使用同一图标库；装饰图标标记 `aria-hidden`，独立图标按钮提供可访问名称。
品牌图标继续使用正式品牌资产，不用通用图标替代。
参照 [Lucide React 官方指南](https://lucide.dev/guide/react/)，不再引入 Heroicons 或复制其 SVG 路径。
