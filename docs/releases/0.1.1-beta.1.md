# 岚径 Lanpath 0.1.1-beta.1

Lanpath 独立客户端首次公开测试版，欢迎反馈桌面与 Android 的设备兼容问题。

## 下载

- Windows x64 / arm64：`-setup.exe` 为安装版，`-portable.zip` 为便携版。
- Android arm64：`_android_arm64.apk`，最低 Android 13，使用 Lanpath 专用 release 证书签名。
- `.nsis.zip` 与 `.sig` 是安装版验签更新产物；普通用户使用安装器或 Portable ZIP。
- `SHA256SUMS` 提供全部发布文件校验值；`prerelease.json` 为测试版更新元数据。

## 本次内容

- 独立 Lanpath 品牌、仓库与应用身份，桌面和 Android 共用页面与 UI。
- 统一 Lucide 图标、移动端卡片与底部导航、主题二级页与强调色。
- 深色模式支持附属 OLED 纯黑选项。
- Windows Portable 的配置、核心、证书、日志和 WebView 数据位于程序旁的 `data/`。
- Windows/Linux 安装版默认数据目录为 `~/.lanpath`，WebView 位于该目录的 `webview/`。

## 使用说明与边界

Windows Portable 需完整解压到可写目录，系统须已安装 WebView2 Runtime；保留 `lanpath.portable` 和 `data/`。
安装版沿用既有旧业务数据目录的兼容规则；原 identifier WebView 目录保留、不自动迁移，外观偏好需重新设置。
Android 应用身份是 `com.ybakiame.lanpath`，不能覆盖旧产品或同包名的 debug 签名安装。请先备份已有配置再处理签名冲突。
测试版「检查更新」打开发布列表，不推进稳定更新通道；Portable 更新需退出后替换程序并保留数据。

本次发布包含 CI 编译、类型/lint/格式、Rust 测试及打包/签名验证。它们不能替代真机的 VPN/TUN、系统代理与真实升级验收。
未提供 Linux/macOS 分发包。Windows updater 签名用于更新来源校验，安装器未配置 Authenticode 代码签名证书。
