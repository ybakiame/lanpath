# Lanpath · 循径设计系统

本文件是 Lanpath 各应用共用的长期产品与设计规范。共用品牌、信息层级、颜色语义、图标和动效；不同平台分别定义导航、密度、窗口与权限交互。当前落地目标为 `apps/desktop`（纯 Rust、NSH 0.6.0，以 Windows 验证为主）；Android 按第 9 节适配，尚未接入新应用宿主。Windows 已接入统一外壳、首次准备流程、配置路径、语义图标与主要交互保护。各页的目标体验与已实现动效分开标记；Android、真实屏幕阅读器及未覆盖设备缩放仍需后续验收。

用户的首要任务：把一个可信订阅变成可用的代理路径，并能判断核心是否运行、系统网络是否由 Lanpath 接管、出错后该做什么。桌面系统代理与 Android VPN 是不同机制，分别命名和解释。

## 1. 产品定位与承诺

**Lanpath，让每一步网络配置都有迹可循。**

产品面向希望掌控订阅、核心与分流规则的桌面用户。第一次使用能够沿着明确的准备流程启动；日常打开能够迅速判断状态；异常发生能够沿证据排查。精确的状态、可解释的生效范围和可恢复的操作，构成持续使用的理由。

| 层次 | 展示原则 | 例子 |
| --- | --- | --- |
| 决策 | 首屏说清当前状态和下一步 | 核心未运行；校验并启动 |
| 依据 | 说明这次决定作用于谁 | 日常订阅、sing-box、本地端口 |
| 细节 | 按需展开技术证据 | 配置原文、核心输出、代理归属 |

### 1.1 能力与信息边界

| 现有能力 | 用户可以完成的任务 | 必须说明的边界 |
| --- | --- | --- |
| 订阅 | 添加、刷新、编辑、设为当前配置来源、查看原文 | 保存或刷新不等于运行中的核心已应用 |
| 双核心 | 库存管理、版本选择、二进制/配置校验、启停 | sing-box 与 Mihomo 运行；mixed/Clash API 仅 loopback |
| Windows 系统代理 | 通过独立普通权限守护接管、精确恢复 | 偏好、实际归属、恢复状态分别呈现 |
| 规则 | 六类匹配、批量输入、筛选、排序、启停 | 保存后重启核心生效；本地预估不是实际路由 |
| 诊断 | 系统 DNS、直连 TCP、保存的 DNS 上游、mixed/Clash 检查 | 各步骤独立；核心运行不能证明互联网可用 |
| TypeScript 覆写 | 本地脚本，Editor 内编辑 | 同步执行；无 import、文件、网络能力；无 YAML 覆写 |
| 工具 | 请求设置、配置预览、日志、加密备份与恢复、外观 | 备份恢复的替换范围沿用现有业务确认流程 |

当前桌面不提供流量遥测、连接管理、节点切换、CPU/内存仪表盘、TUN/VPN、MITM、服务安装或启动项。它们不得以虚构数据、可点击空入口或“即将推出”卡片占据主界面。Android 仍为独立原生库，尚无新应用宿主或 APK。

### 1.2 状态词典

| 中文 | English | 准确定义 |
| --- | --- | --- |
| 当前订阅 | Current subscription | 下次配置合成所用订阅，不宣称已装载到运行核心 |
| 已保存 | Saved | 持久化完成；若影响核心，补充“重启核心后生效” |
| 核心运行中 | Core running | 当前核心进程与运行时报告一致 |
| 本地代理 | Local proxy | 明确显示 `127.0.0.1:端口`，不称“全局网络” |
| 系统代理已接管 | System proxy owned | 守护确认本数据根持有；不等同 VPN |
| 需要恢复 | Recovery required | 有代理归属/恢复证据需处理，保持可见 |
| 状态未知 | Status unknown | 查询失败或缺少证据；不能显示“已关闭” |
| 本地规则预估 | Local rule estimate | 已保存规则在有限上下文中的推断 |
| 配置预览 | Configuration preview | 当前订阅原文；绑定覆写时生成最终配置；不能冒充正在运行的快照 |

## 2. 信息架构与窗口

保留现有 `Page` 身份、业务模块和数据边界。以下分组只调整发现路径，不改变持久化格式或公开接口。

| 分组 | 导航顺序 | 图标语义 |
| --- | --- | --- |
| 使用 | 概览；首页动作打开订阅、覆写脚本与配置预览 Sheet | 布局、层叠文件、代码、文件代码 |
| 配置 | 核心、配置切片、规则、请求设置 | 芯片、分层切片、分支路径、滑杆 |
| 排查与恢复 | 诊断、日志、备份 | 活动脉冲、文本行、归档 |
| 固定底部 | 外观 | 半明半暗圆 |

导航项全部配图标和文本。当前项以完整选中底色、字重和图标强调表达；不增加左侧竖线、选中圆点或多重边框。组名静态，不添加折叠层级。侧栏收缩/展开按钮置于右侧标题栏左端（参考官方画廊布局），同时左侧保留 Lanpath 应用图标徽记；收起后侧栏完全隐去让位给工作区，切换不重建当前页面，不丢失草稿，按钮保留键盘焦点。普通用户导航不放开发画廊。

尺寸为设计目标，按内容和系统文本缩放放宽，不写死文本容器高度：

| 区域 | 最小 | 默认 | 富余空间 |
| --- | --- | --- | --- |
| 窗口 | 960 × 640 pt（原生最小尺寸） | 1180 × 800 pt | 内容最大阅读宽 1200 pt，余量进入工作区 |
| 侧栏 | 192 pt | 208 pt | 上限 232 pt；更宽无额外收益 |
| 页面内边距 | 16 pt | 24 pt | 大窗口 32 pt |
| 表单 | 280 pt | 480 pt | 上限 640 pt，长说明换行 |
| 详情区 | 280 pt | 320 pt | 上限 440 pt；剩余空间优先给列表 |
| 状态栏 | 内容自适应 | 最小 28 pt | 错误用短文案；完整说明在页面 |

在 960–1100 pt 下，概览辅助区域改为一列，列表详情转为 Sheet。主任务和主要操作保持可见。`apps/desktop/nsh.json` 配置启动与最小尺寸，启动 Root 读取同一窗口配置，阻止拖拽压缩到内容不可用。文本放大时仍应换行并允许区域滚动，不能截断恢复动作。

标题栏沿用现有自定义栏和原生窗口行为。标题、操作、窗口按钮分配不同命中区，按钮不参与拖动。品牌不附长标语，页面不再叠加第二条空工具栏。标题栏、侧栏和主体各自延续表面颜色。

滚动归属：侧栏独立；一般页面只滚动正文；表格/日志由列表或编辑器滚动；标题、筛选工具栏和全局状态栏固定。长错误在详情展开，不挤高底栏。正文和可复制输出允许选择。

## 3. 概览与关键旅程

### 3.1 概览：一次阅读完成一个决定

阅读顺序固定：异常恢复（如有）→ 核心状态与主操作 → 当前配置路径 → 系统代理事实 → 常用后续任务。取消没有数据来源的大数字和图表。所有示例值只能存在于标为“演示数据”的独立画廊中。

概览主要面板使用一条细路径连接“当前订阅 → 核心 → 本地代理”。三节点均有标题、真实摘要、可达的详情动作；窄窗口改纵向。路径表示配置依赖关系，不表示实测网络经过这些节点。系统代理单列在路径下方，不与出口节点混为一谈。

已准备时标题为“准备好启动核心”，按钮为“校验并启动”；运行时标题为“核心正在运行”，主操作为普通描边“停止核心”。频繁命令不因希望用户点击而染成主色。代理需要恢复时，在路径面板上方保留警告及“恢复系统代理”，核心状态继续如实显示。

配置摘要显示当前订阅节点数、所选核心版本、本地端口/API、真实运行时长。用属性行和分隔线组织，避免每个数字套卡片。“运行诊断…”“配置预览”是辅助命令，放在摘要之后。

状态优先级用于安排注意力，不覆盖独立事实：启动失败全窗阻断→需要恢复的系统代理→当前在途任务→查询失败→稳定运行/停止。恢复警告与核心在途可以同时出现；冲突命令按现有单飞状态禁用，不能因警告卡片存在就擅自发出恢复命令。

| 场景 | 主要状态 | 下一步 | 不可推断的事实 |
| --- | --- | --- | --- |
| 数据根打不开 | 应用无法启动，保留实际原因 | 关闭冲突实例或按错误处理后重新启动 | 不显示业务空列表或自动选其他目录 |
| 缺订阅/节点/核心 | 显示第一项未满足条件 | 前往对应准备步骤 | 不自动下载核心或授权代理 |
| 配置已准备、核心停止 | 准备好启动核心 | 校验并启动 | 不保证尚未校验的配置可用 |
| 正在启动/停止 | 当前真实阶段，主要按钮 busy | 等待；导航仍可用 | 不使用计时器推算完成百分比 |
| 核心运行、代理未接管 | 本地代理运行中；系统代理未接管 | 诊断或在核心页查看代理偏好 | 不显示“全部流量已保护” |
| 核心运行、代理已接管 | 两个已核实状态分别显示 | 按需诊断/停止 | 不声称外网必然可达 |
| 代理需要恢复 | 持续警告，保留核心事实 | 业务允许时恢复系统代理 | 不把恢复动作等同重启或终止核心 |
| 查询失败 | 状态未知，标明保留的最近值 | 重新检查或查看详情 | 不将未知归属降级为未接管 |

启动阶段直接映射现有 `RuntimeStage`：读取设置→校验二进制→端口预检→合成配置→校验配置→启动进程→等待就绪。阶段可以被跳过或失败，不能假设等长。停止阶段明确显示“恢复系统代理并停止核心”；若恢复失败，保留恢复证据并依据业务结果显示核心事实。

### 3.2 第一次打开

首屏标题“从一个订阅开始”，说明“添加订阅、准备核心，再启动本地代理。”配一个静态路径示意，不转圈。

1. 添加订阅：名称与地址为主字段，User-Agent 与覆写绑定进入高级项。
2. 刷新节点：保存订阅后可继续刷新；失败保留已添加记录和输入，提供重试。
3. 选择核心：明确库存/下载/版本/平台，不预选未经用户决定的安装行为。
4. 校验并启动：用现有真实阶段说明进度；Windows 系统代理一次性确认继续在核心页完成。

步骤是派生状态，不额外保存“完成”布尔值。只强调当前可执行的一步。已具备的数据保持完成标记，可回到相应页面修改。页面切换不终止订阅刷新或核心命令。不能自动打开系统代理确认、自动启动核心或制造百分比。

### 3.3 每日使用

打开 → 看清核心与系统代理两种事实 → 按需启动/停止或诊断 → 关闭窗口。状态不明时优先给出恢复/查询依据，不能用绿色“已连接”概括全部事实。

更换订阅或规则后，附近提示“已保存，重启核心后生效”。若无法证明运行会话与已保存配置一致，始终分别标为“当前配置”和“运行会话”，不猜测“已同步”。精确差异徽标需要未来有可靠会话指纹后才能实现。

### 3.4 出错后继续

错误呈现四件事：发生了什么、影响范围、仍然有效的部分、可执行下一步。技术细节折叠且可复制。失败不清空草稿、不把最近有效摘要变成空列表、不把代理接管失败等同核心停止。

例：“系统代理未能接管。核心仍在运行，可使用本地入口。查看详情后重试或恢复系统代理。”具体动作必须由现有业务状态允许。

## 4. 页面蓝图

| 页面 | 主要对象与布局 | 可见动作与状态 |
| --- | --- | --- |
| 订阅 Sheet | 首页面板中的稳定属性列表；名称、来源、节点、最近刷新、配置来源身份 | “添加订阅…”普通按钮；行内刷新与更多菜单；选择来源与启用分别展示。地址在详情中，不暴露查询令牌；复制原文明确范围 |
| 核心 | 库存/版本列表与运行会话两区；系统代理独立区 | 选择、校验启动、停止；在途只锁冲突动作，导航可用；失败附核心输出。下载进度仅使用真实字节/阶段 |
| 配置切片 | 跨核心受管端口/Clash API 卡片 + `overwrite/sing-box/*.json` 5 段切片（可视化表单 + JSON 源码） | 端口与 API 密钥存于 `app.toml` 并限 127.0.0.1；5 个 sing-box 切片支持表单与原生 JSON 编辑器双模式编辑、格式化、单切片恢复默认（确认）及 `$nodes` 订阅节点展开；纳入加密备份 |
| 规则 | 顶部筛选；有序规则列表；右侧或 Sheet 编辑器 | 类型、匹配值、出口、启用、顺序；持久化在 `rules.json`；上移/下移始终可达，批量输入错误逐行保留；注明重启生效 |
| 覆写脚本 | 首页 Sheet 列表与原生 Editor Dialog | 名称、本地 TypeScript；高亮、行号、撤销与本地提示；保存/取消固定底部，关闭未保存草稿先确认 |
| 请求设置 | 按请求策略和 DNS 分组的表单 | 默认值有说明；字段旁校验；高级项逐步展开；不将配置 DNS 等同系统 DNS |
| 配置预览 | 概览入口、来源摘要、可选择的只读 Editor | 没有当前启用订阅时禁用；无覆写直接读取保存原文，有覆写才合成；错误就地展示；区分预览与运行快照 |
| 诊断 | 域名输入→逐项结果→本地规则预估 | “开始诊断”是表单提交；结果区分通过、失败、跳过、未知；每项可展开证据和时间；带域名进入添加规则 |
| 日志 | 内存/磁盘切换、可用筛选、正文 | 只读编辑器可复制；用户滚动后不抢回底部；只提供已接入的筛选/尾随能力；无日志时说明如何产生 |
| 备份 | 导出与恢复两个区；恢复为独立多步任务 | 密码、预览范围、替换确认、恢复结果；不承诺合并；有真实进度才展示。失败保留可恢复证据 |
| 外观 | 主题小样、明暗模式、窗口背景材质与不透明度、语言、减少动效 | 悬停预览不落盘；点击应用；支持 Windows 11 原生亚克力/云母/不透明材质切换与 45%–100% 自定义不透明度滑块，保存失败回到确认值 |

空状态区分“还没有”“筛选无匹配”“读取失败”“平台不支持”。分别提供添加、清除筛选、重试/详情、平台说明；不得复用一个“暂无数据”。关闭弹层恢复触发点焦点；删除后焦点落到相邻行或添加入口。

## 5. 视觉语言：循径

借鉴 NSH Gallery 的紧凑尺寸、pansy 的行式管理、doona 的信息分区。品牌记忆点放在路径节点与折线图标，表面保持安静。常态使用不透明石墨/冷白表面；玻璃仅可作为未来浮层实验，不能默认叠加全窗渐变、模糊或持续流光。

### 5.2 字体、节奏与几何

界面沿用系统 UI 字体与 CJK 回退：Windows Segoe UI Variable / Microsoft YaHei UI；macOS 系统字体 / PingFang；Linux 系统 sans-serif。代码、地址和快捷键使用系统等宽字体。数字使用 tabular figures，单位与值共基线，不将所有数据改成代码字体。

| 角色 | 尺度目标 | 用法 |
| --- | --- | --- |
| caption | 12 / 18 pt | 元信息、分组名；不低于 12 pt |
| body | 14 / 22 pt | 默认正文、行和控件 |
| section | 16 / 24 pt，600 | 分区 |
| page | 24 / 32 pt，600 | 页面标题 |
| status | 28 / 36 pt，600 | 概览唯一主要状态 |

单页通常四种字号、400/600 两种字重。系统文本放大时最小高度跟随内容增长；长订阅名可两行，完整值在详情或复制路径可达；英语预留约 40% 扩展空间。

间距仅用 2/4/8/12/16/24/32 pt：图标与标签 8，字段与说明 4，属性组 12，面板内边距 16–24，主要分区 24。对齐轴由父容器定义，不能逐项补像素。

圆角沿用现有 4/6/8 pt（小件/控件/容器）。外层 8 pt、内缩 4 pt 则内层 4 pt；不增加巨大药丸卡片。分段选择是一个轮廓，边界只画一次。焦点环 2 pt、间隔 2 pt，外层留足空间；阴影仅用于菜单、Sheet、Dialog、Toast。

尺寸绑定成组件档位：sm 控件最小 28 pt、md 32 pt、lg 40 pt；图标分别 14/16/18 pt；图标按钮为同档正方形。普通行最小 40 pt，带副文案行 56–64 pt。密集规则表可 32 pt，系统大字时增长。

### 5.3 图标和路径资产

导航、动作统一使用 24 × 24 viewBox、1.75–2 线宽、圆端点的线性 SVG 家族。优先制作应用自有的少量路径图标，再扩展一致风格；不混 emoji、字形符号与不同图标库。沿用 `assets/` 正式品牌图标，不另造应用身份。

| 动作/状态 | 形状 | 行为 |
| --- | --- | --- |
| 启动 / 停止 | 播放三角 / 方形 | 随业务状态交换，按钮标签同时改变 |
| 刷新 | 两段环形箭头 | 仅刷新在途旋转 |
| 校验 / 成功 | 盾牌勾 / 圆勾 | 完成后单次显现，静止 |
| 恢复 / 警告 | 回转箭头 / 三角叹号 | 不常驻闪烁 |
| 路径节点 | 文件层、芯片、端口插口 | 图形旁始终保留名称和状态 |
| 更多 / 复制 | 三点 / 双页 | 图标按钮带名称；更多的作用对象进入可访问标签 |

SVG 保持 `currentColor`、不嵌文字。路径图的文字由原生 Text 绘制；移动中的 SVG 路径效果只在浏览器画廊验证意图，正式应用优先用 NSH 原生 transform/opacity/Canvas。不能假设 SVG SMIL/CSS 动画能原样在原生端运行。

## 6. 控件与交互契约

在现有 `src/ui/` 继续扩展，保持业务调用层只传含义、尺寸、状态、slot 和事件。不得为页面暴露颜色/圆角参数。以下是设计职责，不是在本轮新增 Rust API。

| 组件族 | 规范 |
| --- | --- |
| Button / IconButton | primary 仅默认提交；普通管理动作用 outline/default；危险确认用 destructive；hover 洗色、pressed 加深；禁用不响应 hover；loading 保持宽度，文字说明当前工作 |
| Field / Input / Select | 可见标签、说明、就地错误；输入与弹出列表文字共轴；缺失值保留占位；错误不清空原文 |
| Switch / Checkbox | Switch 即时偏好，Checkbox 独立选择；失败回退最近确认值；“保存的系统代理偏好”不能暗示实际归属 |
| Tabs / Segmented | 可见选中面、方向键、正确角色；单个选择底块移动；不拿普通按钮伪造 Tab 状态 |
| ListItem / DataTable | 固定图标、名称、状态、数值、操作槽；增长集合默认虚拟化，按业务 ID 保持选择；整行只保留一个主要动作 |
| Status / Badge | 仅必要分类和状态；错误必须有文字；普通属性不全部包胶囊 |
| Menu / Popover / Tooltip | 一个浮层表面；Menu 是命令，Popover 是局部设置；只图标命令有名称，含糊时有 Tooltip；开菜单期间触发器保持 open 状态 |
| Dialog / Sheet | Dialog 短表单和决定；Sheet 辅助编辑；先处理顶层 Escape；关闭返回触发点；草稿破坏才询问放弃 |
| Empty / Error / Progress | 任务相关文案、保留上下文、一个下一步；骨架只用于真实未知内容；无百分比就显示阶段 |
| Toast | 非关键异步结果；常规切换不重复弹“已保存”；恢复警告保留在任务表面，不依赖 Toast |

鼠标：按钮使用默认光标，外部资源使用手型，正文用文本光标。不可点击的面板不因 hover 浮起。主要操作不藏在 hover 中；更多菜单可通过 Tab 和 Enter 打开。

键盘：Tab/Shift-Tab 按视觉阅读顺序；组内方向键；Enter/Space 激活；Escape 关闭最上层。文本编辑器保留编辑快捷键，不抢全局启动键。首版不承诺尚未实现的命令搜索、全局快捷键或托盘入口。未来快捷键与应用菜单需共享动作定义，macOS 用 Mod/Command，Windows/Linux 用 Control。

屏幕阅读：所有按钮/字段有名称；选择、展开、busy、invalid 和只读状态可读；异步结果只播报阶段变化和最终结果，不逐秒播报运行时长。装饰性路径隐藏，语义顺序由节点文字承担。UIA 角色、名称、选择状态和原生键盘流程需验证；自动化树检查不能替代 Windows Narrator 的实际朗读验收。

## 7. 动效系统与逐屏清单

复用 `motion.rs`：instant 120、fast 180、base 240、slow 360、slower 500 ms；4/8/16 pt 距离；普通按钮 press 0.97、图标 0.95。桌面常用颜色反馈 120 ms、选择/状态 180–240 ms，360 ms 用于少量重要弹层。进入 ease-out，退出 ease-in，位置变化 ease-in-out；退出快于进入。不新增默认提示音。

生效条件：系统减少动效 **或** 应用减少动效任一为真即静止；在途状态文字仍立即可读。离屏、后台、窗口最小化停止持续效果。motion 创建在组件生命周期中，不能随运行时轮询反复创建。

以下 7.1–7.2 是持续实现的目标清单，不能据此推断某个效果已存在；当前原生实现见 7.3。

### 7.4 首页工作面板

订阅与覆写脚本从概览打开右侧原生 Sheet，不再占用独立导航页。面板头部标题和关闭动作固定，内容区独立滚动；订阅编辑与脚本编辑使用原生 Dialog，标题和操作固定，表单/Editor 占用剩余空间。关闭、Escape、遮罩均经过同一草稿确认；后台刷新不因关闭面板取消。

| 变化 | 工具与行为 | 减少动效 |
| --- | --- | --- |
| 打开/关闭订阅或脚本面板 | NSH Sheet 原生边缘位移与遮罩；退出完成后释放面板 owner | 原生 reduce motion；即时完整面板 |

覆写编辑标题为“覆写脚本”，只编辑本地脚本；默认 `function main(config) { return config; }`。高亮采用 NSH 内置 TypeScript 语言支持；补全是本地模板、关键词与配置字段提示，不宣称有完整 TypeScript 语言服务。

| Menu / Popover / Select / ConfirmDialog | 统一 `popover` 表面与 `popup_starting`/`popup_ending`（0.97→1、4pt、fast）；ConfirmDialog `base` 上升 8pt + 缩放 0.97→1 | 即时显隐，无缩放与位移 |
| 组件画廊（`--ui-gallery`） | 左侧分类导航 + 顶部明暗/动效/Mint 快捷栏；全家族图标、表面层级、选择卡片、Sheet/Popover/Menu、语义色板与图形交换演示 | 减少动效时循环旋转与进入位移全部静止 |

配置预览从侧栏移到概览；未选启用订阅时入口禁用，已选择时标题注明当前来源。原文无需合成或联网；有覆写才生成最终配置，并明确未做核心二进制校验。请求设置移除保存快照/脏状态页脚，错误与保存结果就近显示。日志正文和磁盘文件名左对齐，长文件名单行裁切；外观页清理缩放说明与底部状态块，窗口材质和不透明度集中在独立设置组。

窗口最低 960 × 640 pt，由 nsh.json window.minSize 单一配置注入 Rust Root；侧栏可隐藏，恢复入口常驻。页面内容和滚动不因侧栏开合重建。

## 8. 平台、实现与验证边界

| 平台 | 设计适配 | Lanpath 能力边界 |
| --- | --- | --- |
| Windows | 自绘标题栏保留原生贴靠、双击、按钮；缩放 100/125/150/200%；Narrator | 当前主要目标；代理必须通过现有守护，不在 GUI 写注册表 |
| Linux | 沿用窗口管理器和实际 NSH 后端；系统字体、不同缩放、Orca 待验 | 可以构建验证；系统代理守护不可用，隐藏接管操作并解释 |
| macOS | 窗口控件空间从 API 读取，Command、系统菜单；原生材质有不透明回退 | 编译分支存在不等于产品支持验收；不能声称代理接管可用 |
| Web 画廊 | 同样的桌面密度；窄宽重排；浏览器原生按钮/焦点 | 仅视觉和交互原型，全部示例；无核心、网络、文件、代理权限 |
| Android/iOS/TUI | 不纳入本桌面设计实现 | 不从 NSH 跨平台能力推导 Lanpath 产品支持 |

NSH 官方 Gallery 当前主要展示 TSX；本项目是 Rust，不能照搬 DOM、CSS、TSX props。官方最新文档仅作能力参考，具体函数、属性、平台支持需以项目锁定 0.6.0 的依赖源码与编译为准。

### 8.1 接入顺序

1. 在现有原生 `--ui-gallery` 补齐 token、图标、尺寸与全状态；复用 14 个主题 ID，不迁移数据。
2. 接入统一导航与概览路径；继续使用 `AppState` 的运行状态、命令与摘要，不新增第二份状态源。
3. 按订阅→核心→规则→诊断改造主要旅程，再处理覆写、请求设置、预览、日志、备份与外观。
4. 按下表完成逐屏验收后，才称为原生设计已落地。画廊截图不能替代守护恢复和设备验证。

Windows 原生接入保持 `apps/desktop` 工程、应用身份、业务核心、系统代理守护权限与数据格式；未增加依赖或发布入口。新数据根使用 Ocean，明暗与语言默认跟随系统，全部偏好写入 `app.toml` 的 `[ui]` 节。订阅/覆写/请求设置/规则/备份的草稿在离页或关闭时确认；导出、加解密和恢复事务忙碌时阻止离页或退出，等待完成后由用户再次操作。订阅添加可按 Enter，长列表支持筛选与虚拟化，规则删除需二次确认，备份强密码可显式复制。

临时浏览器画廊位于 `.tmp/work/desktop-redesign/`，原生方案、测试记录与截图归档于 `.tmp/work/windows-circulation/`（Windows 实机证据可由记录定位）。共用规范长期维护在本文件，不重命名为 `apps/ui`，不建立新的应用身份或共享运行时。

## 9. Android 延续与适配

本节定义未来宿主的产品形态，不选定宿主技术或跨端共享代码方案，也不代表 VPN 已接入 NSH。当前 `mobile/android` 保留 Kotlin VpnService、网络接口、通知、日志和文件导出，`mobile/lanpath-core` 处理 Go/libbox；仅支持 sing-box，无 MITM。桌面守护与 Windows 注册表逻辑不复用到 Android。

### 9.1 相同的视觉语言，不同的操作空间

配色角色、路径节点、图标笔画、状态名称、内容分层和恢复原则沿用本规范。Android 正文默认 16 sp，辅助文案 14 sp，关键阅读内容不低于 12 sp；控制目标最小 48 × 48 dp。不能直接压缩桌面的 32 pt 按钮或十一项侧栏。

手机使用底部导航：概览、规则、更多。订阅与覆写脚本从概览打开原生面板。更多收纳核心、覆写、请求设置、配置预览、诊断、日志、备份和外观中实际接入的功能；尚未接入的入口不显示。平板可使用导航 rail 和主从布局。返回按钮、返回手势和系统头部遵循 Android；弹层的次序为确认/菜单→Sheet→页面→退出。

概览路径在手机上纵向排列。“当前订阅 → sing-box → VPN 接口”是配置/接管结构，不能作为网络可达性证明。首页首屏优先状态、启动/停止和当前准备步骤；配置细节逐层展开。工具栏不放一排无标签图标，不使用悬浮速度窗遮挡底部导航。

### 9.2 首次授权与状态模型

首次启动连接：用户点击启动→系统 VPN 授权→配置准备→核心启动→真实服务状态。授权被取消时返回“尚未授权”，保留订阅与配置，只在用户再次点击时重试；不循环弹窗。具体顺序以最终宿主和原生服务契约校验，不借桌面原型宣称通过。

| 桌面语义 | Android 对应 | 不能混用 |
| --- | --- | --- |
| 核心运行中 | sing-box 核心运行中 | 不能仅凭 UI 开关判断服务存活 |
| 系统代理已接管 | VPN 服务已启动，系统已授权 | 不写“系统代理已接管” |
| 系统代理需要恢复 | VPN 服务异常或连接已中断（据实际证据） | 不出现 Windows 守护恢复入口 |
| 本地代理端口 | 按原生服务实际能力提供详情 | 不把 loopback 入口等同设备流量接管 |
| 双核心库存 | sing-box 准备与版本信息 | 不显示 Mihomo 切换选项 |

通知是服务状态的延续：明确应用、当前状态与可用停止动作，不显示无数据来源的速度。通知权限、VPN 授权、后台限制是不同状态，就地解释各自影响，避免合并成一个“权限未开启”。锁屏/后台不运行装饰动画；返回应用后读取真实服务状态。

### 9.3 表单、触摸与动效

编辑器和复杂表单使用完整页面，菜单/短选择优先 Sheet；危险替换用原生明确确认。输入法出现时提交动作可达，Return/Next 顺序正确。复制、导出通过真实平台能力，路径展示不暴露宿主目录。长按只作辅助，主要操作有可见入口。

复用第 7 节语义时长和减弱动效策略；Android 系统页面/返回动画优先，不额外叠加一遍横移。开关与按压可遵循原生反馈；无声音也能理解。字体放大至 200%、TalkBack、手势/三键导航、深浅主题、安全区、IME、旋转和后台恢复必须逐项验证。

独立画廊的手机预览只验证内容、颜色、触控尺寸和纵向路径；VPN 授权、通知、返回手势、服务接入与真机性能列为未验证。正式开发前需为 Android 各页面补齐相应状态与 motion inventory，再进入原生宿主实施。
