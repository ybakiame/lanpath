# ADR-0009：Android 授权前置与备份密码计算优化

- 状态：Accepted
- 日期：2026-10-17
- 触发：用户实测小备份恢复约两分钟、首次授权迟到及切页后重复授权。

## 决策

不降低 age scrypt N=2^17，不改变备份 v1。根 workspace 与独立壳分别为 scrypt/salsa20
配置 dev/release package opt-level=3：避免 debug 无优化和 Android release 全局 z 优化
使密码热循环过慢。其余构建环境、发布身份与目标边界不变。

预览解密后的快照及密码仅保留于进程内单槽缓存；返回随机 UUID preview_id，五分钟到期，
新预览替换旧预览。确认仅接受该一次性凭证，消费后不重复解密；生成恢复前加密副本不变。
凭证与快照绑定，不接收替换文件/密码；错误或过期凭证在停止核心前拒绝。
密码使用 SecretString 持有，消费、替换或定时过期时释放，不写磁盘或日志。
API 变更由两端同版本共享层实现，外部备份格式保持兼容。首次正式包含此能力的发布为 0.1.3-beta.1。

Android start_proxy 先取得应用级 try_lock 启动门禁，再请求 VPN 授权，成功后才获取运行
状态锁并执行配置/网络准备。重复启动立即报进行中，不排队；门禁随取消、失败或成功释放。
Kotlin 授权另以 AtomicBoolean 防重复，已授权与回调/发起失败均释放标记。
取消授权不自动再发第二个弹窗。授权撤销后核心原有检查仍生效，用户可再次点击重试。

前端以集中 Mutation key 和 useIsMutating 读取进程内正在执行的启动操作；切页重挂载不再
仅依赖新 observer 的本地 isPending。按钮保持禁用/进度反馈，成功统一刷新运行状态。
下载和配置准备仍受实际网络影响，本次不改变规则集降级、代理或下载超时策略。

## 验证

备份组（含新增凭证测试）在主机 dev 从约 38 秒降至约 1.8 秒；这是主机测试数据，不能替代
Android 真机耗时。验证凭证错误、过期、一次性消费和旧加密往返；以 Query MutationObserver
回归离开页面后全局 pending 仍存在。双端前端、完整 Rust 门禁、Android Kotlin/资源与包构建
按项目命令执行，真实授权弹窗顺序与设备耗时留待设备验收。
